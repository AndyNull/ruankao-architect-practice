## Design Context

### Users

System architect examination candidates use the site on desktop and mobile for focused practice and reference reading.

### Brand Personality

Focused, compact, professional. The interface should support long-form study without distracting decoration.

### Aesthetic Direction

Preserve the existing light study-workbench visual language. The Markdown reader should prioritize readable line length, clear document navigation, and touch-friendly controls.

### Design Principles

- Keep the current information architecture and navigation language.
- Make documents readable without horizontal scrolling on phones.
- Keep source attribution visible and concise.
- Load static Markdown-derived material locally without runtime third-party dependencies.
